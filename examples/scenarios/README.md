# 三档人工评分案例

三组人工输入沿用同一冻结模型。低、中、高表示三组案例的相对风险。概率对应未来两年发生严重逾期或更严重情形的模型估计。

| 案例 | 未取整总分 | 整数展示分 | 预测概率 | 输入 | 完整输出 |
|---|---:|---:|---:|---|---|
| 低风险 | 644.108 | 643 | 1.13% | [JSON](low.json) | [JSON](low-score.json) |
| 中风险 | 586.541 | 587 | 7.74% | [JSON](medium.json) | [JSON](medium-score.json) |
| 高风险 | 474.417 | 474 | 80.34% | [JSON](high.json) | [JSON](high-score.json) |

每组评分从 590.135 分起算，再加上八个入模字段的档分。单元格依次显示原值、档位和未取整档分。

| 字段 | 低风险 | 中风险 | 高风险 |
|---|---|---|---|
| 额度使用率 | 0.08 → (0,0.1] → +27.176 分 | 0.35 → (0.3,0.6] → -0.033 分 | 0.92 → (0.6,1] → -18.089 分 |
| 年龄 | 58 → [50,60) → +0.334 分 | 35 → [30,40) → -5.292 分 | 38 → [30,40) → -5.292 分 |
| 30–59 天逾期次数 | 0 → 0 → +8.173 分 | 1 → 1 → -13.271 分 | 2 → 2 → -23.990 分 |
| 负债收入比 | 0.25 → (0,0.4] → +3.638 分 | 0.3 → (0,0.4] → +3.638 分 | 0.57 → (0.4,0.6] → -3.693 分 |
| 90 天及以上逾期次数 | 0 → 0 → +6.050 分 | 0 → 0 → +6.050 分 | 2 → 2 → -39.521 分 |
| 房地产贷款数 | 1 → 1-2 → +4.388 分 | 1 → 1-2 → +4.388 分 | 0 → 0 → -4.363 分 |
| 60–89 天逾期次数 | 0 → 0 → +2.940 分 | 0 → 0 → +2.940 分 | 1 → 1 → -18.756 分 |
| 家属人数 | 0 → 0 → +1.274 分 | 2 → 2 → -2.014 分 | 2 → 2 → -2.014 分 |

表内分数按三位小数显示。完整精度、WOE、系数和反算概率见输出 JSON。

完成主流程后，可在仓库根目录复算。

```powershell
python scripts/scorecard.py --customer-json examples/scenarios/low.json
python scripts/scorecard.py --customer-json examples/scenarios/medium.json
python scripts/scorecard.py --customer-json examples/scenarios/high.json
```

刻度推导、分数反算及阈值评估见[公开版报告](../../docs/credit-risk-scorecard-report.pdf)。
